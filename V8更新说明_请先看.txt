Sachiの兔喵鸭韩语宇宙 V8.0 — 草莓牛奶学习小屋
==========================================

【本版新增】
1. 奶油白、樱花粉、奶茶色的统一手机网页视觉。
2. 小屋家具从原有8件扩展至43件（新增35件），赠送部分基础家具。
3. 小屋支持触屏拖动家具并自动吸附到4%位置格；保留方向按钮微调、收起、恢复。
4. 小屋兔喵鸭使用你提供的原始角色图抠出的透明 PNG，首页继续保留原来抱吉他的图片；不重新画角色。
5. 情境颜文字：点击角色、点击互动按钮、学习完成、早晚时间等触发不同颜文字；频率受控。
6. 新增间隔复习、今日待复习、四档记忆评分和易错词本。
7. 新增开放词库加载：保留原有约517条词条，并在联网时从 Open Yonsei Korean Vocabulary 开放数据集加载更多词条；前四册原始数据总计3106条记录，去重后预计总词数超过2000条。网站显示实际去重后的数量，而不是虚报固定数量。首次联网加载成功后会在浏览器缓存，方便离线使用。
8. 沿用 V7 的存档键，不清空旧进度。保留导出/导入学习存档。

【重要说明】
- 本版是可部署的功能升级初版，不是此前生成的像素场景概念图的逐像素复刻。新增家具目前以可交互的图标/像素边框风格呈现；若要实现概念图级别的精细像素家具，还需要逐件制作统一的美术素材。
- 2000+扩充词库需要在第一次打开时联网下载，若网络不能访问 GitHub 原始文件/CDN，网站会显示现有词数，不能保证离线首次打开就是2000词。成功下载后存储在当前浏览器本地；清理网站数据会清除缓存。
- 扩充词汇依据《延世韩国语》开源词源单词本，不是官方 TOPIK 2000 词表；等级仅按教材册次映射，可能需要人工复核词义。
- 现有旧存档不会被覆盖，但升级前请先在原站「小屋 → 我的学习存档」点击「导出存档」并妥善保存。

【GitHub Pages 升级方法】
1. 先在原站导出学习存档备份。
2. 解压本 ZIP，找到 index.html、v8.js、v8.css、sw.js、tonyangdeok.png 等文件。
3. 打开 https://github.com/xuanxuanchen452-code/sachi-korean-universe/upload/main
4. 将 ZIP 解压后根目录内的所有文件一起拖入 GitHub 上传页面。不要只上传 ZIP 压缩包；GitHub Pages 不会自动解压 ZIP。
5. 如果 GitHub 显示同名文件，允许更新这些文件；底部点击绿色 Commit changes。
6. 等待 GitHub Pages 更新，打开 https://xuanxuanchen452-code.github.io/sachi-korean-universe/
7. iPhone Safari 若仍显示旧版，刷新页面两次或关闭网页重新打开；旧 PWA 缓存可能需要一点时间切换。
8. 进入「词库」观察实际收录数量；首次联网加载扩充数据可能需要几秒钟。
